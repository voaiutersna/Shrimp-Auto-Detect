TDS Monitor — ระบบตรวจวัดคุณภาพน้ำ

โครงงานตรวจวัดค่า TDS (ปริมาณของแข็งที่ละลายในน้ำ) และอุณหภูมิน้ำแบบเรียลไทม์ ด้วยบอร์ด Arduino UNO R4 WiFi ส่งข้อมูลผ่าน Wi-Fi ไปยังเซิร์ฟเวอร์ Node.js เก็บลงฐานข้อมูล SQLite และแสดงผลเป็นกราฟบนเว็บนี้ พร้อมแจ้งเตือนเมื่อ TDS สูงเกิน 800 ppm ซึ่งไม่เหมาะกับการเลี้ยงกุ้ง

GitHub ↗

ฮาร์ดแวร์

  • Arduino UNO R4 WiFi
  • เซนเซอร์ TDS → A1 (5V)
  • DS18B20 วัดอุณหภูมิ → D2 (ตัวต้านทาน 4.7kΩ ระหว่าง DATA และ 5V)

วิธีทำงาน

  • สุ่มค่า analog 30 ค่า แล้วใช้ค่ามัธยฐานลดสัญญาณรบกวน
  • ชดเชยอุณหภูมิ: 1 + 0.02 × (T − 25)
  • ส่ง JSON ด้วย HTTP POST ทุก 1 วินาที พร้อม x-api-key
  • หน้าเว็บดึงข้อมูลทุก 3 วินาที

เซิร์ฟเวอร์ & API

  • Node.js + Express + better-sqlite3
  • POST /api/readings รับข้อมูลจากบอร์ด
  • GET /api/readings, /api/stats
  • GET /api/export.csv ดาวน์โหลดข้อมูลทั้งหมด

เกณฑ์คุณภาพน้ำ (TDS)

  • < 50 ppm — ต่ำมาก (น้ำกลั่น/RO)
  • 50–299 ppm — ดีมาก
  • 300–799 ppm — พอใช้
  • ≥ 800 ppm — สูง (ไม่เหมาะกับกุ้ง)
